About SP5G & O-RAN

What is SP5G?

SP5G (Special Project 5G) is a comprehensive research platform for studying DDoS attacks and defenses in 5G Open RAN networks, specifically targeting the F1 interface between Centralized Unit (CU) and Distributed Unit (DU).

This platform is designed for security learners, especially beginners, to understand and experiment with DDoS attacks and defense mechanisms in a safe, controlled environment.

What is O-RAN?

O-RAN (Open Radio Access Network) is an initiative to create open, interoperable, and intelligent RAN architectures. Unlike traditional RAN where all components are proprietary, O-RAN allows operators to mix and match components from different vendors.

Key Components:

  • CU-CP (Centralized Unit - Control Plane): Handles RRC and PDCP control signaling
  • CU-UP (Centralized Unit - User Plane): Handles SDAP and PDCP data forwarding
  • DU (Distributed Unit): Handles RLC, MAC, and PHY-high processing
  • RU (Radio Unit): Handles PHY-low and RF processing

F1 Interface:

The F1 interface connects CU and DU components:

  • F1-C (Control Plane): SCTP-based, port 38472, handles control signaling
  • F1-U (User Plane): GTP-U over UDP, port 2152, handles user data

Why F1 is critical: One CU controls multiple DUs. Attacking the F1 interface can cause widespread service disruption, making it a high-value target for attackers.

Project Goals

Educational Value Lower the barrier for security learners to study DDoS attacks and defenses
Research Value Demonstrate security vulnerabilities in F1 interface and develop defense mechanisms
Practical Value Provide working code that learners can study, modify, and extend
Security Value Help operators understand and defend against F1 interface attacks

Key Features

  • 9 Attack Types
  • 3 Detection Layers
  • 6 Defense Mechanisms
  • 5 Scenarios
  • 97% Detection Accuracy
  • 4.8s Recovery Time

How to Use

  1. Start the Dashboard: Run ./sp5g dashboard or python3 dashboard.py
  2. Start 5G System: Click "Start System" in the Overview tab
  3. Select Scenario: Choose a scenario from the Scenarios tab
  4. Launch Attack: Configure and launch an attack from the Attack tab
  5. Enable Defense: Activate defense mechanisms from the Defense tab
  6. Monitor Performance: View real-time metrics in the Performance tab
