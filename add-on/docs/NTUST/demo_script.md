# 데모 스크립트

## 전체 데모 (5분)

### 1. 도입부 (30초)

"안녕하세요. 오늘은 5G Open RAN 네트워크의 보안에 대해 발표하겠습니다.

다들 DDoS 공격이라고 들어보셨나요? 보안 문제가 뉴스에 나올 때면 단골처럼 등장하는 공격 기술이 바로 DDoS인데요, 막연하게만 생각했던 DDoS 공격을 보안 학습자가 쉽게 연구해볼 수 있도록 연구 플랫폼을 만들었습니다."

### 2. 배경 설명 (1분)

"이 프로그램은 5G 통신에 핵심 개념인 기술 오픈소스화에서 출발하는데요, 현재 이 분야에서 대표적인 오픈소스 프로젝트인 OAI를 기반으로 연구 플랫폼을 애드온처럼 추가했습니다.

5G Open RAN은 기지국을 CU와 DU로 분리하는데, 이들 사이를 연결하는 F1 인터페이스가 핵심입니다. F1 인터페이스를 공격하면 하나의 CU가 제어하는 여러 DU가 동시에 마비될 수 있어, 공격 효과가 크게 증폭됩니다."

### 3. 플랫폼 소개 (1분)

"이 플랫폼은 기본적으로 5가지 시나리오가 있습니다:
- 원전 제어 시나리오
- 스마트 시티 교통 시나리오  
- 군사 작전 시나리오
- 공공 행사 방송 시나리오
- 주거 스마트홈 시나리오

네트워크 구성은 5가지가 있으며, 공격 기술은 총 9개, 탐지 기술은 3개, 방어 기술은 6개입니다.

기본 설정된 프리셋 환경 외에도 학습자가 직접 원하는 환경으로 수정 및 적용할 수 있습니다. 각 폴더 내에 원하는 기술 코드를 짜서 넣고 새로고침만 하면 바로 실험해볼 수 있습니다."

### 4. 실제 데모 (2분)

"예시를 보여드리겠습니다.

[대시보드 화면 보여주기]

먼저 5G 시스템을 시작합니다. [시스템 시작 버튼 클릭]

이제 공격을 실행해보겠습니다. F1-U UDP Flood 공격을 선택하고, DU를 타겟으로 설정합니다. [공격 실행]

보시는 것처럼 CPU 사용률이 급격히 증가하고, 서비스 가용성이 떨어집니다.

이제 방어를 활성화하겠습니다. Rate Limiting을 선택하고 활성화합니다. [방어 활성화]

몇 초 안에 시스템이 복구되고 있습니다. 서비스 가용성이 다시 상승하는 것을 확인할 수 있습니다.

이것이 우리의 3-Layer 탐지 시스템과 자동화 방어 메커니즘의 효과입니다."

### 5. 결론 (30초)

"이 플랫폼을 통해 우리는:
- F1 인터페이스의 심각한 보안 취약점을 실증했습니다
- 97% 정확도의 탐지 시스템을 개발했습니다
- 5초 이내 서비스 복구를 달성했습니다
- 보안 학습자의 진입 장벽을 낮췄습니다

완전한 소스 코드와 문서는 GitHub에서 확인하실 수 있습니다. 감사합니다."

## 부분 데모 (공격-방어 예시)

### 시나리오: 원전 제어 시스템 공격

"원전 제어 시나리오를 보여드리겠습니다. 여기서는 정밀 로봇팔이 위험 물질을 다루고 있습니다.

[시나리오 로드]

이제 F1-C 공격을 실행합니다. Massive UE Connection Flooding으로 CU-CP를 공격하겠습니다.

[공격 실행, 성능 그래프 보여주기]

보시는 것처럼 CPU가 95%까지 올라가고, 로봇팔의 네트워크 연결이 불안정해집니다. 만약 실제 상황이라면 위험 물질 노출 위험이 있습니다.

이제 방어를 활성화합니다. Threshold-based Detection과 Rate Limiting을 동시에 적용하겠습니다.

[방어 활성화]

몇 초 만에 시스템이 안정화되고 있습니다. CPU 사용률이 감소하고, 로봇팔의 연결이 복구되고 있습니다.

이것이 우리 플랫폼의 핵심 가치입니다: 실제 작동하는 공격과 방어를 통해 보안을 학습할 수 있습니다."

## 주요 포인트

1. **쉬운 단어 사용**: 기술 용어는 최소화하고 일반인도 이해할 수 있게 설명
2. **시각적 데모**: 그래프와 대시보드 화면을 적극 활용
3. **실제 작동**: 실제 코드가 작동하는 모습을 보여줌
4. **교육적 가치 강조**: 학습자의 진입 장벽을 낮춘다는 점 강조
